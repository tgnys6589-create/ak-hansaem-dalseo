# AK한샘부동산 · 달서구 부동산 브리핑

공인중개사의 고객 브리핑을 위한 반응형 정적 대시보드입니다.

## 공개 데이터 범위

국토교통부 API에서 2026-11-13 조회한 **2026년 10월** 달서구 아파트 매매·전세·월세 신고 거래를 포함합니다. 최신 실시간 데이터가 아닙니다. 취소 신고는 조회 시점 기준 제외되며 이후 정정·취소·지연 신고가 반영되지 않을 수 있습니다.

동별 필터, 기간 선택, 거래건수 Top 10, 주소 검색 지도, 단지 거래 내역, 인쇄를 지원합니다. 4개 추천매물은 가상 샘플입니다. 매물 추가·삭제는 방문자 본인의 브라우저 localStorage에만 보관됩니다. 공유 매물 관리 서버가 아닙니다.

API 키와 서버 코드를 포함하지 않습니다. 가격지수·미분양·주변시설 API는 공개 버전에서 제공하지 않습니다. 지도는 Google Maps 주소 검색을 이용하며 정확한 단지 경계·위치 또는 학군을 보증하지 않습니다. 지도 로딩에는 인터넷 연결이 필요합니다.

## GitHub Pages 배포

이 폴더 내용만 공개 저장소의 main 브랜치에 업로드합니다. 저장소 Settings → Pages → Build and deployment → Source에서 GitHub Actions를 선택합니다. main 푸시 또는 수동 실행 시 pages.yml이 정적 파일을 배포합니다. 실제 주소는 성공한 GitHub Pages 배포 결과를 확인해야 합니다.
